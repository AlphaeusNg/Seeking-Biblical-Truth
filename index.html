The Vision

This vault explores rigorous, communal truth-seeking. One of the core ideas is building better tools for theological dialogue — including community-driven “truth weight” metrics, better summarization, and rich linking/visualization (inspired by Obsidian canvases).

Key Concepts in the Graph

  • • Truth Weight & Epistemic Humility
  • • Logos & rigorous reasoning
  • • Christian Discussion App prototype ideas
  • • Deep study of COC doctrine & salvation

How to Explore

  1. 1. Clone the repo: git clone https://github.com/AlphaeusNg/Seeking-Biblical-Truth.git
  2. 2. Open the folder in Obsidian
  3. 3. Use the graph view + canvases (especially Big Picture.canvas)
  4. 4. Explore the web tools in webapp.py and webapp_v2_grok.py

This public viewer contains a curated slice of the graph for quick exploration. The full vault has significantly more notes and connections.
